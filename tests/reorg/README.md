# Engine API reorg tests

These tests fill `blockchain_test_engine_reorg` fixtures: a labeled block DAG plus an ordered list of Engine API and JSON-RPC steps, run against one fresh client by `consume reorg`. See [the format documentation](../../docs/running_tests/test_formats/blockchain_test_engine_reorg.md).

Most tests port scenarios from client and Hive test suites. This file maps each test to its sources so that a reviewer can compare them and a client team can find the equivalent of its own test. Links point at the client revisions the mapping was checked against. A source listed as an adapted or partial port was reshaped for a black-box Engine API fixture; the module docstring says what was kept.

| Kind | Meaning |
|---|---|
| port | Same chain shape, calls and checks |
| adapted port | Same behavior, reshaped for the fixture format (for example newPayload and forkchoiceUpdated instead of an internal insert call) |
| partial port | Some upstream checks or variants are not reproduced |
| inspiration | Similar scenario, different mechanism or checks |
