# 🧪 Execution-Specs Test Directory

This directory contains the **test cases** that validate the Ethereum Execution Layer specifications. The files here are executed by the specialized test framework to generate test fixtures.

## Structure
The test cases are implemented in Python (`*.py` files) and are typically organized by the **Ethereum Improvement Proposal (EIP)** or **fork** they pertain to.

## 💻 Implementing and Running Tests

To understand how to write, generate, and execute these tests, please refer to the comprehensive documentation for the test framework:

* **Ethereum Execution Spec Tests Documentation:** https://ethereum.github.io/execution-spec-tests/
* **Contribution Guidelines:** [CONTRIBUTING.md](../CONTRIBUTING.md)
