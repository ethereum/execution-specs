# EIP-7954 Increase Maximum Contract Size Test Cases

| Function Name | Goal | Setup | Expectation | Status |
|---------------|------|-------|-------------|--------|
| `test_deploy_size` | Ensure the new max code size boundary is enforced for CREATE transactions | Alice sends CREATE transaction with initcode returning runtime code of parametrized size. Parametrized: `prev_max` (parent fork's `max_code_size()`), `at_max` (current fork's `max_code_size()`), `over_max` (`max_code_size() + 1`). | `prev_max` and `at_max`: contract MUST be deployed with matching code size. `over_max`: contract MUST NOT exist (deployment fails during code deposit). | ✅ Completed |
| `test_create_opcode_deploy_size` | Ensure the new max code size boundary is enforced via create opcodes | Alice calls factory contract which copies initcode from calldata and executes create opcode. Parametrized: `@pytest.mark.with_all_create_opcodes()` (CREATE/CREATE2) × `prev_max`/`at_max`/`over_max` (same size boundaries as `test_deploy_size`). | `prev_max` and `at_max`: child contract MUST be deployed with matching code size. `over_max`: child contract MUST NOT exist (deployment fails during code deposit). | ✅ Completed |
| `test_initcode_size` | Ensure the new max initcode size boundary is enforced for CREATE transactions | Alice sends CREATE transaction with initcode of parametrized size (returns small runtime code `Op.STOP`). Parametrized: `prev_max` (parent fork's `max_initcode_size()`), `at_max` (current fork's `max_initcode_size()`), `over_max` (`max_initcode_size() + 1`, marked `exception_test`). | `prev_max` and `at_max`: transaction accepted, contract MUST be deployed. `over_max`: transaction MUST be rejected with `TransactionException.INITCODE_SIZE_EXCEEDED`. | ✅ Completed |
| `test_create_opcode_initcode_size` | Ensure the new max initcode size boundary is enforced via create opcodes | Alice calls factory contract which copies initcode from calldata and executes create opcode. Parametrized: `@pytest.mark.with_all_create_opcodes()` (CREATE/CREATE2) × `prev_max`/`at_max`/`over_max` (same size boundaries as `test_initcode_size`). | `prev_max` and `at_max`: child contract MUST be deployed. `over_max`: child contract MUST NOT exist (CREATE returns 0, OutOfGasError at opcode level). | ✅ Completed |
